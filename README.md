RealDeal is a Black Friday and Cyber Monday deal finder whose deals were found and price-checked one by one on Black Friday morning, Fri 27 Nov 2026. It lists 29 real deals — TVs, headphones, laptops, phones, gaming and smart home gear at Amazon and Best Buy — each with its product, store, a link to the product at that store, its sale price, its usual price, the discount worked out from those two prices, the time it was checked, the source the price was read from, and an honest verdict (new low, strong price, fair price, or inflated anchor) with the evidence behind it. Search and filters by category, store and discount all work, deals can be sorted five ways, some products are compared across stores, and every deal page shows the full arithmetic. Plain static files, no build step, no network calls: the deals are data in the repository and every figure is computed by the site's own code.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a browser.
